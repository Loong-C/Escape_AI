# Escape 游戏规则
## 1. 基本设定

游戏在水平 $n$ 行、竖直 $n$ 列的方格棋盘上进行（暂时认为 $n$ 取 17）。棋盘的几何中心格子上有一小球，可以向上下左右方向在方格间移动。
两名玩家随机决定先后手。先手使用白桩，后手使用黑桩。白方以左右边界为出口，黑方以上下边界为出口。
玩家可在棋盘任意格点，即方格的角落上放置桩。相邻相同颜色的桩会自动形成墙，小球无法通过墙。
小球处在任意位置时，其通过合法移动跨越边界线离开棋盘的路径称为逃生路径，逃生路径的长度为小球需要移动的步数。在所有逃生路径中，长度最小的逃生路径称为最短逃生路径。

## 2. 桩与墙

未参与任何墙的桩称为浮桩，参与至少一段墙的桩称为锚桩。玩家可以在任意未放置桩的格点放置己方桩。

玩家也可以用己方桩替换对方的一枚浮桩，当且仅当替换后，该桩会立即与至少一枚已有己方桩相邻并形成墙时允许替换。锚桩不能被替换。

桩放置或替换后，其与所有相邻同色桩之间立即形成墙。

## 3. 回合操作

在一个回合中，当前玩家必须选择一个合法位置放置一枚己方桩，或合法替换一枚对方浮桩。然后计算小球当前的全部最短逃生路径。若这些最短逃生路径的第一步全部相同，则小球向该方向移动一步，否则小球不移动；或，等价地，若小球能够上、下、左、右没有墙阻挡地移动到四个格子中的某些，且这些能够移动到的格子处的最短逃生路径长度的值中最小值唯一，那么小球移动到该格子处，否则小球不移动。

每次落桩至多使小球移动一步。小球移动后，本回合立即结束，不再次进行最短逃生路径判定。若小球在此次移动中跨越棋盘边界，则立即进行胜负判定；否则轮到另一名玩家行动。

## 4. 胜负判定

若小球跨越棋盘的左边界或右边界离开棋盘，则白方获胜。若小球跨越棋盘的上边界或下边界离开棋盘，则黑方获胜。若一名玩家落桩后使小球不存在任何逃生路径，则该玩家获胜。若轮到一名玩家行动时，棋盘上不存在任何合法落子或合法替换位置，则游戏和棋。

## 5. 辅助信息

在简单版本的难度中，可以在小球当前格子的上、下、左、右格中心直接展示这些位置的最短逃生路径长度。预览尚未确认的落子时，数字直接切换为落子后的值。最后跨越边界线的一步计入路径长度；若某一方向因为墙的阻挡无法一步到达，则该格子中的值记为 $(+\infty)$。若四个数字中的最小值唯一，可以用颜色标出该值。所有提示仅是公开的局面辅助信息，不参与胜负判定，也不改变小球的移动规则。
