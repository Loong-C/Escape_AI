# 架构与数据边界

Escape AI 分为三层：

1. **棋手**：规则引擎、基准搜索、Policy-Value Network 与 PUCT MCTS。
2. **验证器**：独立 Python/C++ 规则实现、小棋盘精确搜索、高预算复核。
3. **分析器**：Parquet 棋谱、DuckDB 查询、中文研究报告与只读棋谱查看器。

规则状态只包含格点桩位、球所在方格和行动方。墙、锚桩与距离场均为派生信息。渲染对象、动画、UI 筛选状态以及实验日志不进入规则状态。

大型产物默认写入 `G:\Escape\_AI`。若产物总量达到 400GB，或 G 盘剩余空间低于 80GB，生成任务必须先原子写入恢复点，再停止分配新对局。
